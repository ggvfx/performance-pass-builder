Performance Pass Builder

Turns footage into a performance pass — depth with a face mesh over each face you choose, and the original audio.

Hand the result to a video generation model as reference video, to replace the actor and the background while keeping the performance.

What this version handles

  • Constant frame rate sources only. Variable frame rate is refused: frame numbers would not map reliably to time.
  • Up to 1080p and 2,400 frames per hosted depth call.
  • Faces, not bodies. Depth carries the staging; the mesh carries the expression.
  • One window for the whole clip. Per-frame depth ranges would make the depth pump.
