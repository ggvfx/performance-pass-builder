Performance Pass Builder

Turns footage into a performance pass — depth with a face mesh over each face you choose, and the original audio.

Run only the passes you want, then combine them. Outputting one pass on its own is the same thing with one layer switched on.

What this version handles

  • Constant frame rate sources only. Variable frame rate is refused: frame numbers would not map reliably to time.
  • Up to 1080p and 2,400 frames per hosted depth call.
  • Faces, not bodies. Depth carries the staging; the mesh carries the expression.
  • One window for the whole clip. Per-frame depth ranges would make the depth pump.
  • Layers stack and reorder, and nothing else. No opacity, blend modes or masks yet.

The stack

Layer 0 is the bottom. The number is where a layer sits; the switch is whether it takes part. Reorder them, switch off anything you do not want — outputting a single pass is this with one layer on.

  • 3 Face mesh has alpha Not run
  • 2 Depth Not run
  • 1 Plate the original footage Ready
  • 0 Grey card 18% Ready

The mesh is the only layer with alpha, so what is under it shows through: over the plate is how you check a track, over grey is how you look at the mesh alone. Segmentation and other control passes arrive here as more layers, without changing anything above.
